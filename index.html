1. L'Essentiel du Cours

Les règles d'or indispensables pour décrocher les points à l'examen régional et national.

1. Domaine de définition

Pour toutes les fonctions polynômes (sans fraction ni racine) :

Df = ℝ = ]-∞ ; +∞[

C'est la question cadeau au Bac ! Aucun calcul requis.

2. Les Dérivées Simples

Seules 3 règles sont à mémoriser pour la filière Lettres :

  • • Nombre seul : (k)' = 0
  • • Avec x : (ax)' = a (ex: 5x → 5)
  • • Carré : (x²)' = 2x
  • • Général : (ax²)' = 2ax

3. Sens de variation

Le signe de la dérivée f'(x) donne la direction de la courbe :

f'(x) > 0 → f est Croissante
f'(x) < 0 → f est Décroissante
Exemple type d'examen (Modèle 100% conforme)

Étude complète de : f(x) = x² - 4x + 3

1

Domaine de définition :

Puisque f est une fonction polynôme, Df = ℝ.

2

Calcul de la fonction dérivée f'(x) :

Pour tout réel x :
f'(x) = (x²)' - (4x)' + (3)' = 2x - 4 + 0 = 2x - 4.

3

Annulation et signe de f'(x) :

On cherche quand f'(x) = 0 :
2x - 4 = 0 ⟹ 2x = 4 ⟹ x = 4 / 2 = 2.
